# Oxigit Licensing

Oxigit is licensed under the [Business Source License 1.1](LICENSE) (BSL 1.1).

## What you CAN do

- **Self-host** Oxigit for your personal or company use
- **Read, modify, and fork** the source code
- **Contribute** improvements back to the project
- **Use all features** without restriction for internal use
- **Integrate** Oxigit into your development workflow

## What you CANNOT do

- **Offer Oxigit as a hosted service** to third parties (e.g., running a competing "Oxigit Cloud" or rebranding it as your own Git hosting SaaS)

## Automatic open source conversion

Each version of Oxigit automatically converts to the **Apache License 2.0** three years after its release. This means every line of code becomes fully permissive open source — it just takes time.

## Why BSL?

Oxigit is built by a small team. The BSL ensures that the people building the software can sustain development by offering a managed cloud version, while keeping the code transparent and self-hostable for everyone.

This is the same licensing model used by MariaDB, HashiCorp (Terraform), Sentry, and CockroachDB.
