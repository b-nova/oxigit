# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-04-10

### Added

- Initial open-source release
- Git hosting with HTTP and SSH transport
- Web UI with repository browsing, commits, branches, and tags
- Markdown and code rendering with syntax highlighting
- User authentication and SSH key management
- Repository visibility management (public/private)
- Issues and pull requests with numbering per repository
- AI-powered commit analysis and PR summaries
- Docker, Docker Compose, and one-click cloud deploy support
- SQLite-based storage with automatic migrations
